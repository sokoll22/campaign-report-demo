# campaign-report-demo — бриф проекта

> Собран через скилл `demo-project-interview` (живой тест на реальной задаче) — 15.08.2026.
> Демка 2 из бэклога `STRATEGY.md` (веха «Готовность к продаже», срок 31.08.2026).

## Цель

Показать агентству, как рутинный сбор отчёта по рекламной кампании клиента
превращается из ручной работы (~40 минут) в автоматический процесс на
несколько секунд. Агентство загружает таблицу с сырыми метриками кампании —
получает готовый отчёт с выводами и рекомендациями, который можно почти без
правок переслать своему клиенту под своим брендом.

## Аудитория

Маркетинговые, SEO, RevOps и CRM-агентства (5-30 человек), которые продают
клиентам AI-функции, но сами не успевают их делать (только 13% HubSpot-
партнёров реально зарабатывают на AI-услугах при том, что 92% наращивают
AI-бюджеты — в этот разрыв демка и метит). Работа идёт white-label — от
имени агентства, не от имени исполнителя.

## Входит в скоуп

- Загрузка CSV/Excel с общими для любой кампании колонками: дата, канал,
  показы, клики, конверсии, расход, доход.
- Автоматический расчёт ключевых показателей и трендов за период.
- Текстовый отчёт, сгенерированный через LLM: краткая сводка за период,
  3-5 инсайтов простым языком (что выросло/просело/где перерасход),
  рекомендации на следующий период.
- Веб-страница с результатом (Flask, по аналогии с lead-router-demo).
- Честная метрика на странице: «было ~40 минут вручную → стало несколько
  секунд».

## Не входит в скоуп

- Реальное подключение к рекламным кабинетам (Google Ads, Meta и т.п.) —
  только загрузка файла.
- Сохранение истории отчётов между заходами — каждый раз новый файл, новый
  отчёт, ничего не хранится (как в lead-router-demo).
- Работа с несколькими клиентами одновременно — один файл, один отчёт за
  раз, без логина и личных кабинетов.
- Экспорт в PDF — достаточно веб-страницы.

## Граничные случаи

- Файл пустой или не CSV/Excel — понятная ошибка, без технического текста.
- В файле нет нужных колонок (например, отсутствует «расход») — подсказать,
  каких колонок не хватает, а не выдать кривой отчёт молча.
- Строки с пропущенными/нулевыми значениями — не ломать расчёт, честно
  показать в отчёте «данные неполные за такой-то период» (в духе пометок
  quoted/inferred из lead-router-demo).
- Очень маленький объём данных (1-2 строки) — отчёт строится, но без
  «трендов», раз не с чем сравнивать.

## Критерий готовности

- Загружаешь тестовый CSV — отчёт строится и открывается на веб-странице.
- Отчёт содержит все части: сводку, 3-5 инсайтов, рекомендации — осмысленный
  текст, а не шаблонный мусор.
- Показана честная метрика сравнения (было/стало).
- Проверено на 2-3 тестовых файлах, включая один «неидеальный» (с
  пропусками) — для проверки граничных случаев.
- Публикация на публичный адрес — отдельная отложенная задача, в критерий
  готовности самой демки не входит.

## Технические ограничения

- Python + Flask (стек lead-router-demo, не распыляемся на новый инструмент).
- pandas (или csv-модуль) для разбора файла.
- Anthropic API для генерации текста отчёта, с офлайн-режимом без ключа
  (качество ниже, но страница работает).
- Срок сознательно не зафиксирован в брифе — решено делать сейчас
